# 煤炭 or 禮物 — 生圖清單（給 Codex）

> 目標：把目前程式繪製的「暫代角色」換成正式美術。遊戲邏輯不用改，我會另外做一層「圖片載入器」，
> 有圖就用圖，沒圖就退回程式繪製，所以可以**分批交圖、隨時能玩**。

> ## ✅ 目前進度與最終風格決定（以此為準，下方原始清單僅供參考）
> - **畫風規則**：聖誕老人「本人」（主角、分身、開場動畫、肌肉秀、入口頁背景）＝寫實肌肉風（半寫實 cel-shaded、粗深藍外框）；
>   孩子世界裡的一切（好孩子、流氓、哥布林、雪怪、**偽裝的聖誕老人**、禮物/煤炭/愛心/雪堆圖示）＝**韓系貼圖風 Q 版**（約 2 頭身、扁平色、細外框、極簡）。
> - **已完成並接進遊戲（54 張）**：主角 11、好孩子 8、流氓 8、哥布林 8、雪怪 5、偽裝老人 6（韓系 Q 版）、物品與 UI 5、開場動畫 3。入口頁背景輪播 12 張（`assets/bg/`）。
> - **仍是程式繪製**：夜晚雪地小鎮背景、擬聲字/對話框/結算橫幅/粒子。
> - **重新產圖流程**：`tools/jobs/*.json`（Codex 工作清單）→ `tools/gen_with_codex.py` → 原圖放 `assets/_gen/` → `tools/build_sprites_kr.py`（整理成遊戲規格）→ `python tools/build_manifest.py`。
> - 原本寫實版偽裝老人備份在 `assets/_gen/fake_realistic_backup/`。

## 0. 先決定的事（出圖前）

| 項目 | 建議 | 為什麼 |
|---|---|---|
| 畫風 | **粗黑外框的扁平卡通（cel-shaded）**，和現在遊戲的風格一致 | 目標只有約 100~130px 高，細節會被吃掉；粗輪廓、大色塊最好辨識（尤其好孩子 vs 壞孩子） |
| 一致性做法 | 先出**一張角色設定圖（character sheet）**，確認後再用它「參考生成」其他姿勢 | 同一角色跨姿勢走樣是 AI 出圖最大的坑 |
| 圖中文字 | **圖上不要有任何文字**（含中文、英文） | 生成器寫不好中文；文字由程式疊（標題、擬聲字、對話框都已是程式畫的） |
| 透明背景 | 角色/物件一律**透明 PNG**；背景類用 JPG/PNG 即可 | 生成時可先用單色綠底再去背 |
| 解析度 | 以遊戲顯示大小的 **2 倍**出圖（見各表） | 高解析螢幕才不糊 |


**舞蹈參考（來自你給的影片截圖）**：整齊劃一的「猛男團」舞風 — 面無表情、下巴微抬、自信；**手臂大幅度橫向揮擺（可想像甩毛巾）**、胸肌顫動。
- `dance_1`：身體微向左傾、右臂橫向揮出
- `dance_2`：正面站穩、雙手垂在身側/微握拳、胸肌挺出（中間「定格」姿勢，最常出現）
- `dance_3`：與 1 左右相反（身體微向右傾、左臂橫向揮出）

> 4 個**分身**（站在畫面兩側當「伴舞」）直接用同一套 `flex / pump / dance` 圖，顏色由程式在載入時微調色相，**不需要另外出圖**。
> **關於參考影片的版權/肖像**：影片裡的人物與品牌形象只當「氣氛參考」，請做成**原創的聖誕老人角色**，不要畫成任何真人或既有品牌角色的長相。
> 我（Claude）無法直接看 YouTube 影片，只看得到你貼的截圖；舞蹈動作若有更多細節想要，請用文字或多給幾張截圖描述。

## 5. 出圖流程建議（避免走樣）

1. **第一批只做「角色設定圖」**（不到 10 張）：主角聖誕老人、好孩子 a、流氓 a、哥布林 a、雪怪、偽裝老人 — 每個一張全身正面圖，彼此畫風必須統一。**先給我看、確認畫風與好壞辨識度**。
2. 設定圖確認後，用它當**參考圖**逐張生成各狀態/姿勢（reference / image-to-image），別每張都重新從文字開始。
3. 先做 **P0**，一批一批放進 `assets/` 對應資料夾，我這邊分批接上；沒到的圖遊戲會自動用程式繪製頂著。
4. 去背請檢查邊緣有沒有白邊/綠邊（放在深藍背景上最容易看出來）。
5. 全部以 2 倍尺寸出圖，我這邊會處理縮放。

## 7. 接圖方式（載入器已完成）
載入器 `js/art.js` 已經做好並接進遊戲：**有圖就用圖，缺圖（或還沒載完）自動退回現在的程式繪製**，所以可以分批交圖、每次都能玩。

放圖步驟：
1. 圖片放進 `assets/` 對應資料夾（見上面的資料夾結構與檔名）。
2. 在專案根目錄執行：`python tools/build_manifest.py`（掃描圖片、更新清單；只會載入清單裡有的檔案，所以缺圖不會有 404）。
3. 重新整理遊戲。

可調整的設定（選填）：
- `assets/anchors.json`：每張圖的手部位置等錨點，用圖片寬高的比例（0~1）。例如主角出手時投擲物從哪裡飛出去：
  `{ "sprites/santa/release_fwd": { "hand": [0.82, 0.28] }, "sprites/santa/release_up": { "hand": [0.78, 0.12] } }`
  （沒設定時預設在 `[0.80, 0.30]`；圖到了我會幫你量。）
- `assets/units.json`：各類角色在遊戲裡的大小，`{ "santa": 340, "kidGood": 134, "kidBad": 150, "yeti": 460 }`。

程式會處理：左右翻轉、分身色相偏移、投擲時蓄力後仰＋出手前撲、受擊閃白/壓扁/被打飛、彈跳、雪怪被打中閃白、入口頁輪播等。
**我會確認好孩子/壞孩子在 100~130px 大小下仍然一眼可辨**，必要時請你重出該張。
