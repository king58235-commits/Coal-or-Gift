入口頁背景輪播用的「全版肌肉聖誕老人靜態圖」放這裡。

規格建議:
- 16:9 橫向,例如 1920 x 1080(JPG 或 PNG 都可以;JPG 檔案比較小,載入比較快)
- 全版滿版圖,不需要去背。聖誕老人盡量放在畫面中央偏左/偏右,
  因為手機直式會被裁成中間一條,左右邊緣可能看不到
- 畫面中央會疊標題和按鈕,頁面有半透明暗色遮罩保持文字清楚,
  所以圖不用刻意留白

怎麼啟用:
1. 把圖片放進這個資料夾,例如 bg-1.jpg、bg-2.jpg ...
2. 打開 js/entry.js,在最上面的 BG_IMAGES 陣列加上檔名(目前放的是 12 張生成的場景圖,想換圖就改這個清單):
     const BG_IMAGES = [
       'assets/bg/bg-1.jpg',
       { src: 'assets/bg/bg-2.jpg', pos: '30% 50%' },   // pos 可選:手機直式時畫面對準的位置
     ];
3. 重新整理。圖片會隨機輪流淡入淡出(不會連續重複同一張),載入失敗的會自動跳過。

張數不限,越多越有「每次來都不一樣」的惡搞感。
