# Coal-or-Gift（煤炭 or 禮物）🎁🪨

一款惡搞風的瀏覽器小遊戲：**肌肉聖誕老人**要把**禮物**丟給好孩子、把**煤炭**砸給壞孩子。
點擊畫面投擲，連擊會召喚分身伴舞、引來雪怪，還要小心**偽裝成小孩的聖誕老人**——打到他，整個畫面會被他的肌肉秀蓋住。

純 HTML5 Canvas，沒有任何建置步驟、沒有依賴套件，用任何靜態網頁伺服器就能跑。

## 快速開始

瀏覽器對 `file://` 有限制（圖片載入、聲音），**請用本機網頁伺服器**開啟，不要直接雙擊 `index.html`：

```bash
python -m http.server 8765
```

然後開啟 <http://localhost:8765/>（入口頁），或直接開 <http://localhost:8765/game.html>（遊戲）。

## 玩法

| 目標 | 要丟什麼 |
|---|---|
| 好孩子（亮色、圓臉、頭上有光環） | **禮物** |
| 壞孩子（流氓、哥布林：紅眼、獠牙、暗色） | **煤炭** |
| 偽裝的聖誕老人（戴毛帽／頭巾假莫霍克／假尖耳，但有白鬍子、墨鏡、肌肉） | **什麼都別丟** |

### 操作

| 動作 | 按鍵 |
|---|---|
| 投擲 | 滑鼠左鍵／觸控點擊畫面目標（雪怪戰可長按連發） |
| 切換禮物／煤炭 | `1` / `2`、空白鍵、`Q` / `E` / `Tab`、滑鼠右鍵、滾輪，或點左下角按鈕 |
| 暫停 | `P` 或 `Esc` |
| 音效開關 | `M` 或右下角按鈕 |
| 回入口頁 | `H` 或右下角「首頁」按鈕 |

### 規則

- 共 **3 顆愛心**。目標沒處理就離開 → 扣一顆愛心。
- **丟錯**：扣 100 分、連擊減半；**累積 3 次失誤再扣一顆愛心**（左上角有三顆小點顯示；連續打對 10 次可冷卻 1 次失誤）。
- **連擊**：倍率隨連擊上升（最高 5 倍）；每 5 連擊多一個站在畫面邊緣伴舞的**分身**，最多 4 個。
- **雪怪**：連續打對會累積能量條（約 14 次起，每打倒一隻門檻 +3、上限 32）。雪怪出現時要在 10 秒內切煤炭**狂點**打倒；丟禮物只會餵牠回血。打倒 → 場上所有孩子變成好孩子並得分、補一顆愛心；失敗 → 扣愛心、扣 500 分、連擊與能量歸零。
- **偽裝的聖誕老人**：約 20 秒後開始混進目標裡。打到他會觸發全螢幕「肌肉秀」，期間無法投擲；放著不管，他會自己溜走並給你獎勵分數。
- 難度隨時間加速，基準一局約 1.5～2 分鐘。
- **本機排行榜**（前 5 名）存在瀏覽器的 localStorage，遊戲結束畫面與入口頁都看得到。

## 專案結構

```
index.html        入口頁（背景輪播、排行榜、玩法說明）
game.html         遊戲本體
js/
  game.js         遊戲邏輯與繪製（狀態、投擲、目標、連擊、雪怪、肌肉秀、HUD、開場動畫）
  sprites.js      程式繪製的備援角色（沒有圖片時自動使用）
  art.js          圖片載入器：有圖用圖、缺圖退回 sprites.js；分身換色在背景預先處理
  art_manifest.js 由 tools/build_manifest.py 產生的圖片清單（請勿手改）
  entry.js        入口頁：隨機背景輪播、飄雪、排行榜顯示
  scores.js       本機排行榜（localStorage，前 5 名）
  audio.js        WebAudio 合成音效（沒有任何音檔）
assets/
  sprites/        遊戲內角色與物品（主角、小孩、怪物、偽裝老人、雪怪、禮物／煤炭）
  scene/ ui/      雪堆、愛心
  intro/          開場動畫三張全版圖
  bg/             入口頁背景輪播圖
  anchors.json    各張圖的錨點（例如主角出手的手部位置）
tools/            生圖與圖片處理工具（見下）
docs/ART_LIST.md  美術清單、規格與最終風格決定
```

## 美術風格

- **聖誕老人本人**（主角、分身、開場動畫、肌肉秀、入口頁背景）：半寫實的 cel-shaded 卡通，粗深藍外框。
- **孩子世界裡的一切**（好孩子、流氓、哥布林、雪怪、偽裝的聖誕老人、禮物／煤炭／愛心／雪堆）：**韓系貼圖風 Q 版**，扁平色塊、細外框、極簡。
- 開場動畫與肌肉秀**不放效果字**；命中時的 `POP!` / `BAM!` 擬聲字保留。

所有圖片都由 [Codex CLI](https://github.com/openai/codex)（`gpt-6-luna`）生成，並逐張人工審查肢體與一致性。完整規格見 [`docs/ART_LIST.md`](docs/ART_LIST.md)。

## 換圖／重新生圖

遊戲**缺圖不會壞**：沒有對應圖片時會自動用 `js/sprites.js` 的程式繪製版。

1. 把圖片放進 `assets/` 對應位置（檔名規則見 `docs/ART_LIST.md`）。
2. `python tools/build_manifest.py` — 掃描圖片並更新清單（遊戲只載入清單裡的檔案）。
3. 重新整理頁面（必要時 `Ctrl+F5`，瀏覽器可能快取舊版）。

### 工具

| 檔案 | 用途 |
|---|---|
| `tools/gen_with_codex.py <jobs.json>` | 用 Codex 批次生圖（每張獨立呼叫、可並行、自動從 Codex 暫存收圖，拒絕假透明的棋盤格圖）。`--only a,b` 只重跑指定幾張 |
| `tools/jobs/*.json` | 各批生圖的 prompt 與參考圖設定 |
| `tools/prep_sprite.py` | 裁切、縮放、貼底，輸出成遊戲規格 PNG |
| `tools/build_sprites_kr.py` | 把 `assets/_gen/` 的原圖依角色分組套用同一縮放倍率，輸出到 `assets/sprites/` |
| `tools/build_manifest.py` | 產生 `js/art_manifest.js`，可讀 `assets/anchors.json`、`assets/units.json` |

`assets/_gen/` 放生圖原始輸出與審查圖，體積大，已被 `.gitignore` 排除（只留下重新生圖需要的核准參考圖）。

## 常見調整點

| 想調什麼 | 在哪裡 |
|---|---|
| 難度曲線（出現間隔、停留時間、同時目標數） | `js/game.js` 的 `dif()`、`spawnInterval`、`maxConcurrent`、`targetLife` |
| 丟錯幾次扣愛心 | `WRONG_LIMIT` |
| 雪怪出現門檻／血量／時間 | `yetiThreshold`、`startYeti` |
| 偽裝老人出現時機與頻率 | `spawnTarget` 裡的 `dif() >= 55` 那段 |
| 入口頁背景清單與手機對準位置 | `js/entry.js` 的 `BG_IMAGES` |
| 各角色在遊戲中的大小 | `assets/units.json` 或 `js/art.js` 的 `UNIT` |

## 已知限制

- 手機觸控版面沒有在實機驗證過。
- 目前沒有背景音樂；音效是即時合成的。
- 夜晚雪地背景與命中擬聲字、對話框仍是程式繪製。
- 圖片較大，首次載入需要一點時間（主要是入口頁 12 張背景，各約 400～600 KB）。
